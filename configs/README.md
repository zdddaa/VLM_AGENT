# Configs

Planned configuration groups:

- `agent.yaml`: calibrated routing thresholds and retry limits.
- `change_detector.yaml`: detector checkpoint, thresholding, token export.
- `sam3.yaml`: SAM3 Change Adapter and boundary/semantic refinement settings.
- `vlm.yaml`: instruction-tuned temporal VLM inference settings.
- `taxonomy.yaml`: canonical T1/T2 semantic codes and transition constraints.

No fixed scientific thresholds should be copied from README examples without validation-set calibration.
